# 智械边界 · SOVEREIGN

v0.5 · 局部强化、拆除与真实军备库存版

一款离线、单人、四阵营的回合制基地攻防原型。目的不是复刻商业游戏，而是检验“构建—布局—维修—进攻”和可训练副驾驶是否形成有趣的取舍。

## 立即试玩

- 本次 v0.5 已启动的独立试玩地址：**http://127.0.0.1:8766/**。
- 不想启动服务：直接双击本目录的 **index.html**，无需网络、账号或安装。
- 若本机地址以后打不开：双击 **启动试玩.cmd**，默认启动 **http://127.0.0.1:8765/**。如果没有 Node.js，它会提示直接打开 index.html，不会安装任何软件。浏览器存档按访问地址独立保存，切换端口不会自动带入原局。
- 电脑版体验最好；窄窗口与手机宽度也有对应布局，战斗快捷操作位于棋盘下方。

本地服务只监听本机，不是已发布的公网网站，也不提供联网对战。

## 推荐第一局（约 5 分钟了解循环）

1. 在“构建”页升级一次科技，再建一座炮塔。建塔要先选设施，再点击棋盘内侧空格。
2. 进入“布局”：先在“选择防守区域”中选核心基地或一块己方前哨，再点击建筑和空格。也可选布局方案，点击“按所选方案调整本区”。各区独立保存布局，但全领地共享每回合三步；固定节点不可移动。
3. 当前没有损伤时，直接跳过维修。
4. 在进攻阶段选一块虚线边界内的无人区，花 40 算力接管。其他阵营行动后，进入新回合。
5. 下一回合研发机器人或攻城车，点击兵营，把生产类目改成想要的兵种。研发赠送四个试验单位，兵营随后逐回合补充。
6. 向敌方方向扩张。相邻敌方区域可“进入战术部署”：手动选择兵种并点击亮色周界，或点击“AI 出兵”。
7. 在战斗中使用信号、屏蔽、强化或轰炸。支持暂停、1 / 2 / 4 倍速；暂停时不能部署或投弹。空格可暂停，Esc 可取消当前选中的建造或战术弹。
8. 到“AI 训练室”运行 120 个样本，再运行独立测试。看策略配比、布局奖励，以及相同场景下与固定基线的差距。训练可停止，不消耗战局资源。

首回合动作不必全部用完。不要只扩张而忽略防御；敌方也会进攻你的核心。算力不足时可跳过构建、布局与维修，在进攻阶段点击“免费休整 → 下一回合领取算力”。敌方仍会正常行动，不能靠等待实时时间恢复算力。

## v0.5：先站稳，再继续强化

- **占领当回合保护：**无论接管无人区还是攻下前哨，该区域在本回合不能再被其他阵营攻击。例：R3 拿下 E7，R3 敌方不能反夺；R4 先完成构建、布局、维修，进入进攻后 E7 可正常遇袭。保护不是永久安全，也不是额外整回合免战。
- **各家先整备，再依次进攻：**玩家进入进攻时，所有存活敌方先完成本轮构建、布局、维修；随后玩家进攻、敌方按序进攻。刷新不会让敌方重复花钱或重复行动，因此 AI 接管前哨后也有巩固机会。
- **敌方也有真实库存：**同一新局各家均为 460 算力、T1、产线 L1、12 无人机 + 10 机器狗。部署扣库存，幸存返回，阵亡消耗；新兵种必须研发，补充来自主基地未被摧毁的兵营，不再按回合凭空生成进攻军队。各家收入、生产、扩张费用和攻城奖励使用同一规则。
- **兵力透明：**“兵力 / 生产 / 战损”可查看各家算力、已研发兵种、库存、生产配置、最近补充与战损。没有战争迷雾是此原型便于核对的设计。
- **归属仍唯一：**每格始终只有一个主人。日志最新在上，按事件编号区分先后，显示“原主人 → 新主人”；旧日志保留原文，不凭空补写历史归属。
- **每区独立防守：**核心基地布局只用于核心格，前哨使用本区域保存的设施位置和战损。可以从地图选己方格后点“查看 / 调整本区防守”，或用防守区域下拉框切换。普通前哨初次生成有三类布局，之后不会每次交战重新生成。
- **行动预算共享：**每回合全领地共用构建 2 次、布局 3 步、维修 2 次。前哨只能增建防御设施，含节点最多 5 座；占领原敌方核心时保留原设施，即使超过 5 座也不删除，但不可继续增建。兵营生产和反应堆收入只统计己方核心基地。
- **设备可持续整备：**只有构建阶段可以增建、局部强化或拆除。强化消耗 1 次构建行动和算力，保留当前生命比例并提高耐久；设施强化等级受科技限制，炮塔强化也会提高伤害。拆除不能处理核心或已损毁设施，返还原价约 30% 算力并释放前哨容量。布局阶段不能增建或强化。
- **训练不等于应用：**AI 训练只更新建议。要改变防线，需在布局阶段选区域并点击应用；每次实际移动扣 1 步，换位也需要借空格，较大方案可能分回合完成。
- **战斗与回放一致取景：**实际防守和回放使用遇袭区域的设施快照，并标注区域坐标。旧版未记录坐标的回放会明确提示未知，不假定它是大本营。占领后保留塔位及损伤，只重启本区节点。
- **旧存档兼容：**保留原存档键、战局、玩家库存、布局和训练数据；刷新原来的地址即可更新，无需“新建推演”。原来没有库存的 AI 仅初始化一次 12 无人机 + 10 机器狗，高级兵种仍需研发。刷新不会补满兵力；旧战局的既有算力和科技不会被强行重置，进行中的战斗保留原快照。

## 规则速览

| 系统 | 本原型规则 |
| --- | --- |
| 胜负 | 四家阵营；阵营核心失守则出局，最后存活者胜利 |
| 世界 | 9 × 9 格，四向相邻拓展；富矿格提高收入 |
| 基地 | 每区 12 × 12 格；核心基地最多 13 座；普通前哨增建上限 5 座（含节点），占领的原核心保留设施；构建阶段可拆除并返还约 30% 算力 |
| 构建 | 全领地共享两项行动，共用于科技、军备研发、产线、增建、局部强化和拆除 |
| 布局 | 全领地共享三次移动，每区独立保存；AI 也遵守占位与步数限制 |
| 维修 | 全领地最多修复两座，价格为损失耐久 × 0.16 向上取整 |
| 进攻 | 进入此阶段时所有敌方先整备；玩家一次占领、攻城或休整后，敌方依次行动 |
| 整备保护 | 新取得区域当回合不可反夺；下回合整备后恢复可攻击，双方适用 |
| 无人区 | 相邻格花费 40 算力直接接管 |
| 攻城 | 最长 60 秒；击破区域节点获胜，获得 70 算力 |
| 出兵 | 双方从库存扣兵；每次容量 12 + 科技等级 × 4；幸存返回，阵亡消耗 |
| 科技 | T1—T3，升级会保留设施损伤比例；新兵种仍需另行研发 |
| 生产 | 主基地未摧毁兵营每回合生产 4 / 6 / 8 单位，最多两类；储备上限 60 / 类；摧毁后停产 |
| 收入 | 80 + 每己方格 8 + 每富矿格额外 10 + 每完好反应堆 25 |
| 战术弹 | 共享每回合 5 能量：信号 1、屏蔽 2、强化 2、轰炸 3 |

**前哨与阵营核心不同：**普通敌方格子也有指挥节点，打掉它只夺取这一格。只有世界地图上标记“核心”的格子失守，才淘汰整个阵营；其余领地随后中立。

五种兵种：无人机、机器狗、重装机器人、磁轨攻城车、信息干扰队。防御设施：加农炮、激光塔、信息屏蔽器。兵营和反应堆分别负责生产与经济。

## AI 到底学到了什么

这是本机运行的**上下文 epsilon-greedy 多臂老虎机**，不是大语言模型、深度学习或完整强化学习寻路。

- 进攻：识别三类基地，在六种预设兵种配比之间探索，按攻陷结果与损毁比例更新平均奖励。
- 防守：识别三类威胁，学习三个预设布局哪个更合适。应用时按实际步数移动，不允许无条件重排所有建筑。
- 每个训练样本包含一次进攻模拟和一次防守模拟；使用与试玩相同的战斗规则与固定模拟步长。
- 进攻奖励 = 是否攻陷核心 + 损毁比例 × 0.5。
- 防守奖励 = 是否守住核心 + 剩余耐久比例 × 0.5。
- 弱侧投放、优先目标与局部避让由规则决定，**没有训练任意部署点、逐格建塔或寻路**。
- 36 个固定的未训练场景，同兵力、科技和种子，对比固定“均衡协同”策略。重复测试使用同一批场景；过度按这批结果调参会降低其独立性。
- 训练结果可能波动或比基线更差。训练曲线不是当前战局胜率，有限测试不能证明所有场景都变强。

敌方使用规则策略与真实战斗模拟，会相互交战、研发、扩产、维修和扩张；只能出自己实际有库存且已研发的兵种。各家全领地共享每轮 2 项构建、3 步布局、2 次维修。AI 在核心和前线之间分配有限操作，不是每个区域都免费强化。训练室是独立沙盒，不消耗或补充战局库存。

经济和出征库存已统一，但不能据此宣称完全公平：敌方暂不使用战术弹，核心固定守军仍是独立的机器狗 + 无人机小队，不扣双方出征库存；手动操作和 AI 策略能力也不同。

## 存档与安全

- 所有代码、说明、测试与截图放在本目录的 D 盘。
- 不安装依赖，不修改系统文件，不调用云 AI，不上传数据。
- 自动存档存在浏览器 localStorage；包括战局、学习表和进行中的战斗。浏览器通常会在自己的配置目录保存少量数据，因此不承诺 C 盘零写入。
- 127.0.0.1、localhost 和直接打开文件是不同存档环境，建议固定一种方式试玩。
- “新建推演”只替换本浏览器当前战局，保留训练结果。手机上可从规则手册底部重开。
- 关闭本地服务窗口可停止服务；退出或重新启动应用后，原服务可能需要重新启动。

## 已验证 / 暂未实现

**已验证：**65 项自动规则测试，包括当回合保护、次回合可反夺、旧存档一次性迁移、敌方真实库存与逐军种战损、统一生产收入、共享预算、所有敌方先整备、防重复和过期结算。网页已走通接管 D7 / E7、下一回合整备、在 E7 增建激光塔并扣费、刷新保留，以及 B5 真实攻城投入 20 / 阵亡 2 / 返回 18、敌方研发生产和深蓝攻陷紫晶核心淘汰阵营。390 px 宽度的整备页与库存弹窗无横向溢出；以往版本的建造、研发、生产配置、攻城、战术弹、暂停加速、训练与回放验证作为历史记录保留。

**原型限制：**未联网；未做自由逐格布局学习、复杂寻路、战争迷雾或商业级平衡；敌方暂不用战术弹，固定核心守军独立于出征库存；防守独立评测尚未单独展示；无限兵力下不承诺防线永不失守，强化与战术弹用于增加选择而不是制造无敌防御；没有覆盖所有浏览器和触屏设备。没有回合上限或领地积分胜利，整备保护改善立即反夺，但不保证每局在固定回合内结束。
